# 招聘岗位：LLM 应用开发工程师（后端方向）

## 岗位职责
- 负责企业级 LLM 应用的后端开发，包括 RAG 知识库、Agent 系统的设计与落地。
- 设计并优化检索增强生成（RAG）全链路：文档解析、切分、向量检索、重排、评测。
- 使用 LangChain / LangGraph 构建 Agent 与多 Agent 工作流。
- 负责服务的工程化：FastAPI 接口、流式输出、缓存、容器化部署。

## 任职要求
- 本科及以上学历，计算机相关专业，2 年以上后端开发经验。
- 熟练掌握 Python，熟悉 FastAPI 或类似 Web 框架。
- 深入理解 RAG 全链路，有向量数据库（Chroma/FAISS/Milvus）实战经验。
- 熟悉 LangChain / LangGraph，理解 Tool Calling、Agent 执行循环。
- 有 Prompt 工程与评测（LLM-as-a-Judge）经验者优先。

## 加分项
- 有 MCP 协议、GraphRAG、多模态 Agent 落地经验。
- 熟悉 Docker、vLLM / Ollama 等部署与推理优化。
- 有开源项目或技术博客。

## 薪资范围
25K - 45K，13-16 薪，五险一金，弹性工作。
