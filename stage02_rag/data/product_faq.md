# 云启智能助手 产品 FAQ（节选）

> 虚构示例知识库，用于 RAG 课程演示。产品「云启智能助手」纯属虚构。

## 产品定位

云启智能助手是一款面向企业的智能知识库与对话机器人平台，支持上传企业文档构建专属问答机器人，并可通过 API 接入企业自有系统。

## 版本与定价

云启智能助手提供三个版本：

- 免费版：支持上传最多 50 个文档，每月 1000 次问答额度，仅支持网页端使用。
- 专业版：每月 299 元/账号，支持上传最多 5000 个文档，每月 5 万次问答额度，支持 API 接入与团队协作。
- 企业版：定制报价，文档与问答额度不限，支持私有化部署、SSO 单点登录、专属客户成功经理。

免费版与专业版之间支持随时升级，升级后按比例补差价。专业版降级为免费版会在当前计费周期结束后生效。

## 支持的文档格式

平台支持上传 PDF、Word（.docx）、Markdown、TXT、HTML 以及 CSV 格式的文档。单个文件大小上限为 50MB。扫描版 PDF 需开启 OCR 选项（仅企业版支持）才能被正确解析。

## 数据安全

所有上传的文档在传输和存储过程中均采用 AES-256 加密。免费版与专业版数据存储于公有云，企业版支持私有化部署，数据不出企业内网。平台已通过等保三级认证。

云启科技承诺不将任何客户上传的数据用于模型训练。

## API 接入

专业版及以上版本提供 RESTful API。接入步骤：在控制台「开发者」页面创建 API Key → 阅读 API 文档 → 调用 `/v1/chat` 接口发起问答。API 默认限流为每秒 10 次请求，企业版可申请提升。

API 调用返回的结果中包含 `answer`（答案文本）、`sources`（引用的文档片段列表）与 `request_id`（用于问题排查）三个字段。

## 常见问题

问：为什么机器人回答说"未在知识库中找到相关内容"？
答：通常是因为相关文档未上传、文档解析失败，或问题表述与文档用词差异过大。建议检查文档是否上传成功，并尝试换一种问法。

问：问答额度用完了怎么办？
答：可在控制台购买加量包，或升级到更高版本。额度每月 1 号重置。

问：支持多语言吗？
答：支持中文、英文、日文的文档问答。跨语言问答（如中文提问、英文文档）专业版及以上支持。
